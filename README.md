## Jennie Kim Icon Portfolio

A beautifully tailored landing page modeled after the style and career milestones of Jennie Kim. Built using standard semantic HTML5 structures and clean CSS layout and configurations.

## Setup Instructions

1. Clone this project repository locally
2. Launch the 'index.html' file in any updated web browser to explore the design layout.
